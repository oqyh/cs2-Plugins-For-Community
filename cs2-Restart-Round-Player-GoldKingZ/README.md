## 📥 Installation

### Plugin Installation
1. Download the latest `Restart-Round-Player-GoldKingZ.x.x.x.zip` release
2. Extract contents to your `csgo` directory
3. Configure settings in `Restart-Round-Player-GoldKingZ/config/config.json`
4. Restart your server
